01 / OPEN-SOURCE WORK

Creator & maintainer

SpeechKit

SpeechKit brings live dictation, meeting transcription, local translation, and natural read-aloud into the editor where people already keep their notes.

I built it to replace a fragmented set of speech tools with one coherent workflow—one settings surface, one model manager, and one set of commands inside Obsidian.

One workflow, deliberately connected
Live dictationStreaming words → Markdown
Meetings & audioTranscripts, timestamps, speaker labels
TranslationPreview before applying changes
Read-aloudLocal voices and in-editor controls

SpeechKit works locally once its models are installed—no account, telemetry, or required cloud service. Optional LLM tools stay separate and use only a provider the person chooses.

Under the hood: a TypeScript Obsidian plugin, Rust native sidecar, and model support across macOS, Windows, and Linux.
